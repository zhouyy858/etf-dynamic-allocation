# ETF 动态配置策略（Codex Skill）

五只 ETF 长期动态配置的 Codex Skill：**每周三调仓、目标缺口当日 1 笔成交、5% 国内 + 5% 海外固定底仓（v18）**；闲置现金全部做国债逆回购；内含可复现回测框架、静态基准对比、压力测试与投资执行手册（**v18 定稿，2026-08-03**）。**纯场内执行：只用五只场内 ETF，不用场外基金/联接申赎。**

> **最近更新（v18 底仓优化，2026-08-03）**：底仓由「15%国内+15%海外」改为「**5%国内+5%海外（总10%）**」——61 组网格搜索（`scripts/exp_base_search.py`）证明总底仓 10%~15% 平台 Calmar 最优：全历史 MDD **-9.07%→-5.79%**、Calmar **1.82→2.70**（real 窗口 25.82%→**28.09%**、MDD -6.65%→**-5.32%**、Calmar 3.88→**5.28**）；2015 股灾 -17.2%→**-11.0%**、2018 熊市 +0.3%→**+2.1%**、共振熊市 -3.4%→**-0.04%**，19-21 牛 27.0%/-8.9%→**26.8%/-5.2%**（收益持平、回撤减半）。代价：全历史 CAGR 16.57%→15.66%（-0.9pp，换 36% 回撤压缩）、2021-22 熊 +4.5%→+3.5%。v17 执行纪律（周三 1 笔）不变。**另测底仓 10%+10%（v19 备选，`references/final_cfg_v19.json`）：全面介于 v17/v18 之间，未超越 v18 定稿**（详见手册 §0.8）。

## 策略作用

- **目标**：在约束回撤的前提下最大化长期复合收益——熊市靠红利/现金收缩回撤，牛市放大成长弹性，攻守一体。
- **标的**：159232 自由现金流ETF（A股价值防御）、515100 红利低波100ETF（A股红利底仓）、159941 纳指100ETF（海外AI成长）、513500 标普500ETF（美股均衡龙头）、159952 创业板ETF（A股成长弹性）。
- **机制**：双市场（A股/美股）9 维均线打分 → 状态 0-9 → 动态权重；叠加结构闸门、快刹车、深熊锁定、组合回撤上限、波动率刹车五层风控。

## 核心执行规则（硬性约束）

1. **每周三决策、当日 1 笔成交（v17）**：每次目标缺口在决策当日 1 笔全部成交（收盘前完成）；紧急风控（快刹车/深熊锁/速度刹车/组合回撤上限）任意交易日**当日 1 笔生效**并取代旧计划。网格搜索 40+ 执行方案证明 1 笔全面优于原「分 3 周三笔」（全历史 16.57%/-9.07% vs 13.49%/-11.91%）。
2. **双市场底仓固定不动（v18）**：国内 159232+515100 合计 5%、海外 159941+513500 合计 5%（各 2.5%），合计 10% 永不清零（原 15%+15%=30% 经 61 组网格搜索优化：总底仓 10%~15% 平台 Calmar 2.5-2.8，熊市防御增强、牛市进攻不降，见 v18 更新块）。
3. **现金管理**：闲置现金全部配置国债逆回购（回测按年化 2.2% 日计息）。
4. **费用与纪律**：单边费万 5 逐笔计入；调仓缺口门槛 min_delta=2% 过滤微小调仓；**QDII 溢价门控**（场内溢价 >5% 海外成长弹性×0.6、>8%×0.3、>12%×0.15；溢价率 >3% 买入暂缓、>5% 仅场内减量/暂缓，**绝不转场外联接基金**）。

## 回测结果（v17 定稿，数据截至 2026-07-31）

| 口径 | 年化收益 | 最大回撤 | 夏普 | Calmar |
|---|---|---|---|---|
| 全历史代理 2014-06-23 起（含 2015/2018/2021-22 三轮大熊） | **15.66%** | **-5.79%** | 1.71 | **2.70** |
| 真实 ETF 窗口 2025-04-23 起 | **28.09%** | **-5.32%** | 2.21 | **5.28** |

- 静态基准 B1-B7 全历史回撤 -28%~-37%，本策略 -9.07% 回撤减半以上，夏普/Calmar 全面领先。
- v17 = v15 策略参数 + **1 笔立即执行**（原分 3 周三笔）：全历史 CAGR 13.49%→16.57%、MDD -11.91%→-9.07%、Calmar 1.13→1.83。
- 三熊市压力测试（v17）：2015 股灾 -17.2%/-11.6%、2018 **+0.3%**/-8.0%、2021-22 +4.5%/-7.8%，全面优于 v15（-19.3%/-14.1%、-2.7%/-9.2%、+3.1%/-8.1%）与静态基准。
- **跨境共振压力测试**（合成：美股累计-30% + A股-20%）：v15 回撤 **-11.2%** vs 静态基准 -26%~-40%（v17 共振测试见 `scripts/stress_test.py` 更新）。
- **诚实边界**：全周期（含三轮大熊）年化 16.57%/回撤 -9.07%，首次同时逼近"20% 年化"与"<10% 回撤"目标；真实窗口 25.71%/-6.65% 达标。

## v16 防过拟合验证结论（本轮不调参的理由）

- **扰动审计**（`scripts/audit_robustness.py`，76 次 ±10/±20% 单参数扰动）：CAGR 平台 12.5%~13.9%，多数参数扰动影响 <0.2pp；仅 3 次 Calmar 恶化 >10%——全部是"放宽风控"方向（`max_eq` 下调、速度刹车阈值放宽、成长骨架大幅上调），说明 v15 没有靠极端参数撑收益。
- **WFO 样本外**（`scripts/wfo_test.py`）：训练 2014-2021 选出的最优参数在 2022-2026 OOS 窗口 Calmar 1.24，与 v15 全样本参数 OOS 的 1.23 基本一致——全样本定稿参数不是对历史行情的记忆。
- **预注册变体证伪清单**（`references/exp_v16.json`，12 个）：波动率目标激活（休眠，被既有风控层级前置）、打分 2 周确认（双差）、滞后增强（MDD 劣化）、去溢价门（双差）、去速度刹车（MDD -14.82%）、溢价转国内（收益回撤双输）、成长骨架 x1.05/1.1（Calmar 下降）——均不采纳。
- **框架敏感性**：决策日信号若滞后 1 日（周三收盘决策-收盘成交惯例），proxy -1.22pp/real +0.66pp，方向随窗口变化，判定为时序假设差异而非系统性收益幻觉，已在自评中记录。

## 使用方法

**安装**：把本目录放到 `~/.codex/skills/etf-dynamic-allocation`（Codex 自动发现）；或在 Codex 中直接要求"对五只ETF做每周三动态调仓回测"。

**运行回测**（需 pandas/numpy）：

```bash
python3 scripts/run_backtest.py          # 完整回测：DYN vs B1-B7 基准 + 分阶段 + 仓位现状 + 终端图表
python3 scripts/run_backtest.py <cfg.json> <tag>   # 自定义参数
python3 scripts/stress_test.py           # 七情景压力测试（牛市/震荡/三轮熊市/跨境共振合成）
python3 scripts/search.py 120 23         # 参数再优化（真实窗口 CAGR>=20% 且 MDD>=-10%）
python3 scripts/audit_robustness.py references/final_cfg_v17.json v17 "[1.0]"  # 防过拟合: 参数扰动审计(1笔执行)
python3 scripts/exp_schedule_search.py    # 执行方案网格搜索(周几x频率x笔数x比例)
python3 scripts/wfo_test.py              # 防过拟合: 样本内/样本外验证
python3 scripts/exp_v16.py               # 防过拟合: 预注册变体批量证伪
python3 scripts/daily_automation.py      # 每个交易日09:00由launchd触发: 拉数→日报→通知
```

输出写入当前目录 `out/`；图表为终端 ASCII（不生成图片文件）。
每日日报（信号/仓位/目标/调仓动作/**QDII 溢价监控**/组合表现）保存到 `~/ETF策略日报/reports/`，并通过 macOS 通知提醒；可选 Server酱(微信)/Bark(iOS) 推送见 `SKILL.md`。
