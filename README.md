# ETF 动态配置策略（Codex Skill · v21 无未来函数口径）

五只 ETF 长期动态配置的 Codex Skill：**每周三用前一日收盘信号决策（无未来函数）、目标缺口分 3 周三笔（三周调整完）、5% 国内 + 5% 海外固定底仓、现金 50% 逆回购 + 50% 国债ETF（v21 定稿，2026-08-04）**。纯场内执行：只用五只场内 ETF，不用场外基金/联接申赎。含可复现回测框架、未来函数审计、静态基准对比、压力测试与投资执行手册。

> **⚠️ v21 未来函数修正（2026-08-04，重要）**：外部审查发现原 v17-v20 回测存在「当日收盘信号 + 当日收盘成交 + 成交仓位计提当日收益」三重超前口径，收益被系统性高估。已修复并重校准：
> - **修复**：① `signal_lag:1` 决策只用前一日收盘信号（周三早盘用周二数据）；② 引擎 `accrual_mode=pre` 先计提当日收益、后收盘成交（成交份额自下一交易日起计收益）；③ `premium_shift:2` QDII 溢价严格用 T-2 口径（QDII 净值 T+1 晚间发布）；④ 执行恢复每周三 **3 周三笔**（严格口径下反超 1 笔，real Calmar 4.41 vs 3.42）；⑤ 底仓维持 5+5（严格口径网格 + 扰动 + 压力测试验证，2.5+10/0+10 历史 Calmar 略高但美股危机/共振熊更差）。
> - **修正后业绩（2026-07-31 数据）**：全历史代理 CAGR **10.23%** / MDD **-9.69%** / Sharpe 1.09 / Calmar **1.06**；真实 ETF 窗口 **24.44%** / **-5.33%** / Sharpe 1.98 / Calmar **4.58**。旧发布口径 16.20%/28.10% 含未来函数，已作废（复现：`scripts/audit_lookahead.py`）。
> - **诚实边界**：「年化 20+%」仅在真实窗口（1.3 年科技牛）成立；全历史严格口径真实 CAGR 约 10%、MDD <10% 达成。**不再承诺 20% 年化。**

## 策略作用

- **目标**：在约束回撤（<10%）的前提下最大化长期复合收益——熊市靠红利/现金收缩回撤，牛市放大成长弹性，攻守一体；长期主义者、钱永不离开市场。
- **标的**：159232 自由现金流ETF（A股价值防御）、515100 红利低波100ETF（A股红利底仓）、159941 纳指100ETF（海外AI成长）、513500 标普500ETF（美股均衡龙头）、159952 创业板ETF（A股成长弹性）。
- **机制**：双市场（A股/美股）9 维均线打分 → 状态 0-9 → 动态权重；叠加结构闸门、快刹车、深熊锁定、组合回撤上限、波动率刹车、QDII 溢价门控、跨市场相关性风控、下跌速度刹车八层风控。

## 核心执行规则（硬性约束）

1. **每周三决策、3 周三笔（v21）**：只用截至前一日收盘数据决策（无未来函数）；目标缺口分 3 笔——决策周收盘成交 1/3，随后 2 个周三各 1/3，三周调整完；计划不重叠；紧急风控任意交易日触发并当日生效。
2. **双市场底仓固定不动（v18 起维持）**：国内 159232+515100 合计 5%、海外 159941+513500 合计 5%（各 2.5%），合计 10% 永不清零。
3. **现金管理（v20 起）**：闲置现金 **50% 国债逆回购（2.2%）+ 50% 国债ETF（511010）**——与组合收益相关 -0.10，提升闲置资金收益并平滑回撤。
4. **费用与纪律**：单边费万 5 逐笔计入；调仓缺口门槛 min_delta=2%；**QDII 溢价门控**（T-2 口径：>5/8/12% → 海外成长弹性 ×0.6/0.3/0.15；溢价 >3% 买入暂缓、>5% 仅场内减量，绝不转场外联接）。

- **静态基准对比（proxy 全历史，严格引擎）**：B1 等权 20 / B2 保守 / B3 均衡 / B4 成长 / B5 价值 的 CAGR 14.1%~14.4%，但 MDD **-27.8%~-33.2%**（Calmar 0.42~0.51）；v21 用约 4pp 年化换回撤减半以上，Calmar 翻倍（1.06 vs ≤0.51）。
- **压力测试（v21）**：2015 股灾 +7.25%/-11.88%、2018 熊市 +9.55%/-8.96%、2021-22 熊 **+8.35%**/-6.89%（熊市仍正收益）、2019-21 牛 +10.91%/-8.16%、跨境共振熊（合成美股-30%+A股-20%）**-2.04%/-7.71%**。
- **分阶段（proxy）**：2015 股灾 -8.9% 累计、2018 -0.2%、2021-22 +8.5%、2019-21 牛 +36.9%、2024Q4-2026 双牛 +25.5%；平均现金 55%。
- **严格口径底仓网格**：国内底仓加码放大 A 股危机回撤、海外底仓加码提升收益；Calmar 平台在 cn=0~2.5/us=7.5~10（1.21），但 5+5 对称在美股危机/共振熊最稳、扰动失败最少（2/76）、real Calmar 最优（4.58），定为 v21。

## 未来函数审计（`scripts/audit_lookahead.py`，可复现）

1. 同一引擎双计提模式（`accrual_mode=pre/post`）+ 信号滞后（`signal_lag`）+ 成交滞后（`exec_lag`）做时序口径对照，并**断言旧口径可复现 v20 发布值**（16.20%/28.10%）；
2. 结论：虚高 ~37%（proxy）来自「当日信号 + 成交仓位计提当日收益」；修复后前日信号口径在严格引擎下与同日信号持平或更优（动量追涨在无未来口径下无边际信息）；
3. 附带压力测试（严格 B vs 旧口径）与 `out/audit_lookahead.json` 结果存档。

## 使用方法

```bash
python3 scripts/run_backtest.py                      # 完整回测（默认 v21）：DYN vs B1-B7 + 分阶段 + 仓位现状 + 终端 ASCII 图
python3 scripts/run_backtest.py <cfg.json> <tag>     # 自定义参数
python3 scripts/audit_lookahead.py                   # 未来函数审计（口径对照 + 旧口径复现校验）
python3 scripts/stress_test.py                       # 压力测试（牛市/震荡/三轮熊市/跨境共振合成）
python3 scripts/audit_robustness.py references/final_cfg_v21.json v21   # 防过拟合：参数扰动审计
python3 scripts/wfo_test.py                          # 防过拟合：样本内/样本外验证
python3 scripts/daily_automation.py                  # 每个交易日 09:00 由 launchd 触发：拉数→日报→通知
```

输出写入当前目录 `out/`；图表为终端 ASCII（不生成图片文件）。每日日报（信号/仓位/目标/调仓动作/QDII 溢价监控/组合表现）保存到 `~/ETF策略日报/reports/`，macOS 通知 + 可选 Server酱/Bark 推送。
