# ETF 动态配置策略（Codex Skill）

五只 ETF 长期动态配置的 Codex Skill：**每周三调仓、每次目标分 3 周三笔（每周三 1/3）完成**；15% 国内 + 15% 海外固定底仓；闲置现金全部做国债逆回购；内含可复现回测框架、静态基准对比、压力测试与投资执行手册（**v14 定稿，2026-08-03**）。

> **最近更新（v14）**：① 新增跨市场相关性风控（CN/US 40日滚动相关 >0.30/0.42 → 成长弹性 ×0.85/0.65）；② 逆回购利率更新至 2.2%（2026 实际利率）；③ 共振熊市压力测试 MDD 降至 -12.5%；④ 每日日报含 QDII 溢价监控。

## 策略作用

- **目标**：在约束回撤的前提下最大化长期复合收益——熊市靠红利/现金收缩回撤，牛市放大成长弹性，攻守一体。
- **标的**：159232 自由现金流ETF（A股价值防御）、515100 红利低波100ETF（A股红利底仓）、159941 纳指100ETF（海外AI成长）、513500 标普500ETF（美股均衡龙头）、159952 创业板ETF（A股成长弹性）。
- **机制**：双市场（A股/美股）9 维均线打分 → 状态 0-9 → 动态权重；叠加结构闸门、快刹车、深熊锁定、组合回撤上限、波动率刹车五层风控。

## 核心执行规则（硬性约束）

1. **每周三执行调仓**：每次目标缺口分 3 笔，在决策当周及随后 2 个周三各成交 1/3，**三周调整完**；计划不重叠（上一计划未完成则常规决策顺延），紧急风控任意交易日可触发并取代旧计划（仍分 3 周三笔）。
2. **15% 双底仓固定不动**：国内 159232+515100、海外 159941+513500 各 7.5%，合计 30% 永不清零。
3. **现金管理**：闲置现金全部配置国债逆回购（回测按年化 1.8% 日计息）。
4. **费用与纪律**：单边费万 5 逐笔计入；调仓缺口门槛 min_delta=2% 过滤微小调仓；**QDII 溢价门控**（场内溢价 >5% 海外成长弹性×0.6、>8%×0.3、>12%×0.15；溢价率 >3% 买入暂缓、>5% 用场外申赎替代）。

## 回测结果（v13，数据截至 2026-07-31）

| 口径 | 年化收益 | 最大回撤 | 夏普 | Calmar |
|---|---|---|---|---|
| 全历史代理 2014-06-23 起（含 2015/2018/2021-22 三轮大熊） | **13.32%** | **-14.82%** | 1.22 | 0.90 |
| 真实 ETF 窗口 2025-04-23 起（牛市） | **28.46%** | **-5.61%** | 2.21 | 5.08 |

- 静态基准 B1-B7 全历史回撤 -28%~-37%，本策略 -14.82% 回撤减半，夏普/Calmar 全面领先。
- v14 = v13 + 跨市场相关性风控（共振熊市 MDD -13.1%→-12.5%）+ 逆回购利率 2.2%（全历史 CAGR 13.21%→13.32%、MDD -14.99%→-14.82%）。
- 三熊市压力测试：2015 股灾 -19.6%/-14.3%、2018 -2.8%/-9.2%、2021-22 +2.9%/-8.3%，显著优于基准。
- **跨境共振压力测试**（合成：美股累计-30% + A股-20%，2024-09~2026-07 窗口）：DYN v14 回撤 **-12.5%**（v10 -15.0%）vs 静态基准 -26%~-40%。
- **分阶段**：牛市 2019-21 CAGR 23.0%/-8.0%、2024Q4-2026 双牛 17.4%/-7.9%、2021-22 熊市 +3.1%/-8.1%、2018 熊市 -2.7%/-9.2%。
- **诚实边界**：全周期（含三轮大熊）无法同时达到"年化 20% + 回撤 <10%"（搜索前沿约 13%/-15%）；牛市情景 28.0%/-5.6% 达标。

## 使用方法

**安装**：把本目录放到 `~/.codex/skills/etf-dynamic-allocation`（Codex 自动发现）；或在 Codex 中直接要求"对五只ETF做每周三动态调仓回测"。

**运行回测**（需 pandas/numpy）：

```bash
python3 scripts/run_backtest.py          # 完整回测：DYN vs B1-B7 基准 + 分阶段 + 仓位现状 + 终端图表
python3 scripts/run_backtest.py <cfg.json> <tag>   # 自定义参数
python3 scripts/stress_test.py           # 七情景压力测试（牛市/震荡/三轮熊市/跨境共振合成）
python3 scripts/search.py 120 23         # 参数再优化（真实窗口 CAGR>=20% 且 MDD>=-10%）
python3 scripts/daily_automation.py      # 每个交易日09:00由launchd触发: 拉数→日报→通知
```

输出写入当前目录 `out/`；图表为终端 ASCII（不生成图片文件）。
每日日报（信号/仓位/目标/调仓动作/**QDII 溢价监控**/组合表现）保存到 `~/ETF策略日报/reports/`，并通过 macOS 通知提醒；可选 Server酱(微信)/Bark(iOS) 推送见 `SKILL.md`。
