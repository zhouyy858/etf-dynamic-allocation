## 策略作用

- **目标**：在约束回撤（<10%）的前提下最大化长期复合收益——熊市靠红利/现金收缩回撤，牛市放大成长弹性，攻守一体；长期主义者、钱永不离开市场。
- **标的**：159232 自由现金流ETF（A股价值防御）、515100 红利低波100ETF（A股红利底仓）、159941 纳指100ETF（海外AI成长）、513500 标普500ETF（美股均衡龙头）、159952 创业板ETF（A股成长弹性）。
- **机制**：双市场（A股/美股）9 维均线打分 → 状态 0-9 → 动态权重；叠加结构闸门、快刹车、深熊锁定、组合回撤上限、波动率刹车、QDII 溢价门控、跨市场相关性风控、下跌速度刹车八层风控。

## 核心执行规则（硬性约束）

1. **周五决策、1 笔当日收盘成交（v22）**：只用截至前一日收盘数据决策（无未来函数）；目标缺口 1 笔当日收盘成交（分笔平滑在严格口径下纯属时滞损失——信号侧已有滞回 0.66/0.24 + 2 周确认，S 阶段 45 组网格实证 1 笔全面胜出）；计划不重叠；紧急风控任意交易日触发并当日生效。

## 使用方法

```bash
python3 scripts/run_backtest.py                      # 完整回测（默认 v23）：DYN vs B1-B7 + 分阶段 + 仓位现状 + 终端 ASCII 图
python3 scripts/run_backtest.py <cfg.json> <tag>     # 自定义参数
python3 scripts/audit_lookahead.py                   # 未来函数审计（口径对照 + 旧口径复现校验）
python3 scripts/stress_test.py                       # 压力测试（牛市/震荡/三轮熊市/跨境共振合成）
python3 scripts/audit_robustness.py references/final_cfg_v23.json v23   # 防过拟合：参数扰动审计
python3 scripts/search_v22.py S|F|P|G                # 全参数重训各阶段（可复现）
python3 scripts/daily_automation.py                  # 每个交易日 09:00 由 launchd 触发：拉数→日报→通知
```

输出写入当前目录 `out/`；图表为终端 ASCII（不生成图片文件）。每日日报（信号/仓位/目标/调仓动作/QDII 溢价监控/组合表现）保存到 `~/ETF策略日报/reports/`，macOS 通知 + 可选 Server酱/Bark 推送。
