3. **未来是 AI 科技的天下** → 纳指100 超配：成长拆分 bull 57.6%→**65%**、bear 33%→**40%**。含义：纳指100是组合内最纯粹的 AI/科技载体；高溢价期全额转低溢价标普（AI 敞口不消失、不付溢价风险），溢价正常期持更多纯纳指。A 股科技代理（创业板）受前提②约束保持低配。
4. **红利低波周期转换时间较长** → CN 红利底仓 0→**4%**（159232 自由现金流 + 515100 红利低波100 各 2%，深熊锁中也持有、持续收息）；防御动量拆分（159232 vs 515100，80 日窗口）不做短周期切换。含义：红利低波风格轮动是多年尺度周期，不能在周期中途因短期回撤下车——底仓穿越周期收息，防御拆分只跟随相对动量不放大切换频率。**v30 降为 2%**（各 1%）：前提仍生效（底仓存在、深熊锁存活），但 2015/2016 CN 熊承压减半——这是回撤破线修复的主要来源（CN 底仓轴 1→4% 平滑单调，2% 是回撤 <10% 的上限）。

**前提与版本映射**：前提①②③④ → v28（④与③共同支持 CN 底仓 4%）→ 前提③的进一步表达 → v29（纳指超配）→ **v30 中间态（CN 底仓 4→2、创业板 28→30：前提②④弱化但全部保留，回撤压回 10% 内）**。v27 为纯历史拟合最优（proxy Cal 1.82），v28/v29 为前提一致的最优但破 10% 验收线，v30 为「前提全部生效 + 回撤达标」的中间态（详见「版本迭代性能下降分析」）。

**为什么测量上"变差了"？**——因为回测以历史为真，而前提认为历史的一部分不可外推：

1. **前提②（创业板震荡）压低 Proxy 端收益**：回测里创业板是历史"怪兽"（2015/2019/2024 三轮大牛，proxy 全历史 +173%），v27 的 proxy 收益大量来自它；降权 35%→28% 后这些历史收益不再计入（proxy CAGR 11.74→11.55，-0.19pp）。**这是主动的选择：前提②认为创业板历史牛市不可外推，未来震荡市里多持创业板只会加噪声和换手损耗。**
2. **前提①（美股向好）+ 前提④（红利低波周期长）加深熊市段回撤，并把最深回撤段从 2020-03 移到 2015-16**：v27 最深回撤 -6.46% 发生在 2020-03 美股崩盘（当时组合已快速降到 20% 权益，损失被速度刹车限制）；v28/v29 最深 **-10.35%** 发生在 2015-06~2017-06 CN 熊（含 2016-01 双市场下跌）——US 底仓 10%（+2.5pp）+ CN 红利底仓 4%（+4pp）在下跌路径上持续暴露是加深主因（2015-08 CN 大跌、2016-01 熔断时底仓全程承压）。压力测试对照：2015 股灾 MDD -6.80→-8.43、2018 -5.12→-6.10。**这是持有底仓穿越周期的代价——前提④明确要求不在周期中途下车。**
3. **real 窗口 CAGR 下降（30.07→28.41）是前提②的直接体现**：真实窗口里 2025 年创业板大涨（+88%），v27 吃到最多；v28/v29 主动少持创业板（2026-06/07 创业板 -18.8% 剧烈震荡段则显著少亏：段内 DD -3.35% vs -4.01%）。一增一减正是"震荡市少持"前提的兑现。

## 使用方法

```bash
python3 scripts/run_backtest.py                      # 完整回测（默认 v30）：DYN vs B1-B7 + 分阶段 + 仓位现状 + 终端 ASCII 图
python3 scripts/run_backtest.py <cfg.json> <tag>     # 自定义参数
python3 scripts/audit_lookahead.py                   # 未来函数审计（口径对照 + 旧口径复现校验 + v20-v30 断言）
python3 scripts/stress_test.py                       # 压力测试（牛市/震荡/三轮熊市/跨境共振合成）
python3 scripts/audit_robustness.py references/final_cfg_v30.json v30   # 防过拟合：参数扰动审计
python3 scripts/search_v22.py S|F|P|G                # 全参数重训各阶段（可复现）
python3 scripts/daily_automation.py                  # 日报：拉数→日报→更新README→推送（Codex 定时任务 每交易日 09:00）
python3 scripts/week_retrain.py                     # 每周重训：拉数→全参复检→三关验证→升级/维持→推送（Codex 定时任务 每周五 16:00）
```

输出写入当前目录 `out/`；图表为终端 ASCII（不生成图片文件）。每日日报（信号/仓位/目标/调仓动作/QDII 溢价监控/组合表现）保存到 `~/ETF策略日报/reports/`，macOS 通知 + 可选 Server酱/Bark 推送。
